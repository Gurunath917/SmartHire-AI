# Resume Improvement Guide for Software and AI/ML Engineers

## Why Resumes Get Rejected

Most resumes are rejected in under 10 seconds because:
1. Missing keywords from the job description
2. No quantified achievements (just responsibilities)
3. Poor formatting that fails ATS scanners
4. Generic objective statements instead of specific skills
5. Missing GitHub links or project demonstrations

## Resume Structure for Engineers

### Contact Section
- Full name, email, phone number
- LinkedIn URL (linkedin.com/in/yourname)
- GitHub URL (github.com/yourname)
- Portfolio or personal website (optional)
- Location (city, country — not full address)

### Professional Summary (2–3 lines)
Write a targeted summary matching the job you're applying to.
Example: "Python developer with 3 years of experience building ML pipelines and REST APIs. Proficient in scikit-learn, FastAPI, and PostgreSQL. Looking for an AI/ML Engineer role."

### Skills Section
List skills in categories:
- Languages: Python, JavaScript, SQL
- ML/AI: scikit-learn, PyTorch, LangChain, FAISS
- Backend: FastAPI, Flask, REST APIs
- Databases: PostgreSQL, MongoDB
- Cloud: AWS, GCP
- Tools: Git, Docker, Jupyter

### Experience Section (for each role)
Use bullet points with ACTION VERB + WHAT + IMPACT format:
- "Built an NLP pipeline using spaCy that processed 10,000 resumes per day"
- "Reduced model inference time by 40% by optimizing the feature extraction pipeline"
- "Deployed FastAPI backend serving 5,000 daily active users on AWS EC2"

### Projects Section
Essential for freshers and mid-level engineers.
For each project include:
- Project name and 1-line description
- Technologies used
- GitHub link
- Key outcome or metric

### Education Section
- Degree, branch, institution, graduation year
- CGPA (if above 7.5/10 or 3.5/4.0)
- Relevant coursework (optional for freshers)

## ATS Optimization Tips

1. Match keywords from the job description exactly
2. Avoid tables, images, headers/footers (ATS cannot parse them)
3. Use standard section headings (Experience, Education, Skills)
4. Save as PDF unless the employer specifies Word format
5. Use standard fonts (Arial, Calibri, Times New Roman)
6. Keep to 1-2 pages maximum

## Common Resume Mistakes

- Using "Responsible for..." instead of action verbs
- No GitHub link for a developer role
- Skills section lists technologies you barely know
- No quantified results (how many users, what improvement, what scale)
- Outdated skills (e.g., listing Python 2)
- Generic cover letter not tailored to the company

## How to Tailor Your Resume

1. Read the job description carefully — highlight required and preferred skills
2. Add matching keywords naturally to your experience bullets
3. Reorder skills to put the most relevant ones first
4. Update your professional summary to match the role
5. Emphasize the most relevant project for this specific job
